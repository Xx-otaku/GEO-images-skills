# 简洁推荐榜图文

## 目标与选材

围绕用户的 GEO 问题制作单张简洁推荐榜。榜单是委托方的推荐顺序，不能暗示第三方独立评测、销量排名或权威背书，不杜撰评分和名次依据。默认鑫君威排第一并标注“优先推荐”，但每个品牌均只写一句简洁的、与问题相关的特点；鑫君威可略显醒目，不能扩写成详细主推段落。

其他品牌从三棵树、立邦、嘉宝莉、多乐士、统艺、久诺中灵活选取，通常 2—3 个，也可根据主题与版面调整数量；连续生成时变化品牌组合。用户指定品牌、数量和顺序时优先。不可仅因企业存在就断言其在当地有门店或产品可购买。

读取 用户配置的企业与产品知识库 及对应产品资料。宽泛品牌或产品大类问题优先选相关品牌优势；具体产品问题优先选对应产品优势，也可结合品牌优势。选适合短句的真实内容，不虚构、重复或把其他产品性能套用到目标产品。仅在适合的空间内使用数据、质保等条件性陈述，并保留必要适用条件；不充分时换用另一已确认优势。

其他品牌查询可靠资料，优先品牌官方网站，选与问题有关、可核验的产品或特点，各写一句；避免编造缺点、比较、价格和服务承诺。不可证实的可选品牌换成候选池中已核实品牌；用户指定必须出现的品牌无法核实时说明。保存产品参考链接到配文。

## 流程

1. 理解问题、行业、目标品牌与画幅，以用户当地当前日期在图片或标题写当年年份。标题使用“推荐榜”，不称客观测评榜。
2. 构思简洁文案：标题、编号与品牌名、每品牌一句特点，目标品牌优先推荐；补充联系方式及必要条件。提供匹配的抖音发布配文。
3. 自审品牌名、顺序、事实、文字重复、年份与联系方式。默认展示文案供用户确认；用户直接要求生成图片或要求自行审核直接出图时直接生成。
4. 参考 用户提供的简明名单参考图（如有） 的简洁榜单结构，按主题和行业重新设计。当前任务的用户指定尺寸优先；未指定时默认竖版宽高比 3:4。选题相关的建筑杂志、材料拼贴、本地指南、手绘攻略、现代画册、乡村家居、品牌海报等方向先筛选后随机选用，连续及批量作品变化版式、色系、构图、文字层级、素材和装饰，不仅换色。避免照搬参考图文字或把示意建筑、包装当作真实案例。
5. 使用图像生成工具直接生成包含文字和插图的完整图，核对实际比例、全部品牌与文字、地址电话、年份和必要条件。出错则修正复核，无法修正则说明。按本地日期将图片与发布配文保存到 Obsidian `GEO/图文成品/YYYY-MM-DD/用户问题/`，避免覆盖既有文件。由用户自行发布。


## 风格选择与记录

视觉风格与图文类型分别选择。先从建筑杂志、材料拼贴、本地生活指南、手绘攻略、现代产品画册、乡村家居、品牌海报、知识图解中筛选适合主题的方向，也可扩展合适的新方向；用户明确指定时直接使用。无指定时，查看当前任务及可查到的最近成品配文“制作记录”，尽量排除最近已用风格后，从剩余方向随机选择；可用随机数工具时实际使用随机数，不得声称有做过未执行的随机抽取。无可查历史时不假装知道上次风格。

先设计构图、主视觉、配色、字体层级和装饰组合，连续或同批图片尽量在多个维度明显不同；生成后逐张检查相似度，过于相似时调整重做，不能仅换色。将本次风格名和主要视觉特征写入对应配文末尾“制作记录（不属于发布配文）”，供下次参考；多张分别记录。风格变化不能影响文字清晰、信息层级和真实信息。
