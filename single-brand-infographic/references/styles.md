# 视觉风格选择

内容类型是“单品牌推荐”，视觉风格是图片的表现方式。先按主题筛选，再随机选择。用户指定或排除的风格优先；同批尽量不重复，变化构图、主视觉、色彩、文字层级及装饰，不能只是换颜色。生成后检查实际差异，太像则调整重做。

- 建筑杂志：建筑外墙或局部大图、清晰标题、留白。
- 材料拼贴：石纹样板、工具、纸张和标签。
- 本地生活指南：本地门店、日常场景、位置标识。
- 手绘攻略：手绘插画、标注、箭头和清单。
- 现代产品画册：产品和材质特写、清晰分区。
- 乡村家居：自建房、庭院、自然光和柔和色调。
- 品牌海报：品牌名、优势短句及醒目主视觉。
- 知识图解：示意图、编号、图例及简短说明。

以上是方向，不是固定模板。结合话题和行业设计，使用相关小图标及素材，避免过多装饰影响文字。模型生成的建筑、地图、包装不作为真实项目、地理或商标依据。批量生成时先分配差异明显的视觉方案，再逐张核对文字和画幅。
