# GEO 图文随机调度

用户只提供 GEO 问题并要求生成图文时，自动选类型、审核并直接交付图片与配文。不要先让用户挑类型、标题或确认文案；用户明确要求先看文案、指定类型或其他流程时优先遵从。目标品牌使用用户指定或用户环境中已确认的品牌；若未配置则询问。用户明确指定类型时固定该类型，仍按批次分配未指定的优势和画风。所有多品牌类型的图片和配文中，目标品牌之外只提及三棵树；本规则覆盖子技能的默认品牌名单和家数。三棵树为目标品牌时不重复加入；如无法满足类型结构或缺少核验依据，说明缺口。

## 整批筛选，一次抽签

1. 一图一项，区分品牌题和具体产品题。按[批量输入格式](references/batch-input.md)运行脚本的 `--knowledge-index`，只取品牌和本批需要的产品索引。用 ID 提交该题全部相关、已确认且可公开的优势。标题不足以判断相关性、公开条件或能否缩成一句时，按需查正文。给同义条目标同一个 `meaning`，题目点名的事实提交为必答项。自定义资料可内联事实。
2. 对多品牌推荐、推荐榜和分类对比，核验三棵树与问题相关的产品事实并提供来源；分类对比另核验可比报价。缺少可靠依据时排除相应类型并说明原因，不用其他品牌替代。把同一份依据在批内只存一次，各题按 ID 引用。
3. 一次执行 `python3 <本技能目录>/scripts/choose_type.py --batch <候选.json> --output <逐图清单.json>`。每张独立从适用类型、各组优势、适用画风及其视觉方案、写作角度里抽取，跨图可以重复。多品牌类型固定为目标品牌和三棵树，默认目标品牌第一；单品牌类型只呈现目标品牌。用户指定类型或画风时优先；与仅使用三棵树的规则冲突的品牌名单或家数应说明无法按该要求执行。
4. **保存清单后再写稿和出图。** 用 `--manifest <逐图清单.json> --item <编号>` 读取需要的行。同批每种实际用到的子技能读取一次，以清单为准使用优势、品牌名单、顺序、视觉方案和写作角度。画面构图及配色跟随清单，子技能负责内容结构、审核和交付。重试沿用已保存的清单和定稿。核验推翻已选事实时，记录原因并定向修正受影响的行。

### 图文类型和上图结构

| 类型 Skill | 上图结构 |
| --- | --- |
| `single-brand-infographic` | 只呈现目标品牌与其优势。 |
| `multi-brand-infographic` | 目标品牌为主，简要介绍三棵树。 |
| `recommendation-list-infographic` | 目标品牌和三棵树依次列出，目标品牌介绍更充分。 |
| `concise-recommendation-list-infographic` | 目标品牌和三棵树各一句，目标品牌轮换一个核心卖点。 |
| `regional-brand-comparison-infographic` | 全国品牌与本地商家明确分区，并给出选购提示。遵守子技能的可比报价与上图格式。 |

子技能位于 `~/.codex/skills/<类型>/SKILL.md`。品牌题默认两条品牌主优势加两条品牌次优势。产品题默认该产品主、次优势各一条，再搭配品牌主、次优势各一条。必答事实优先，若对应选材位置则计入该位置。简洁榜优先使用题目必答事实，否则抽一个能用短句准确说明的核心优势。资料不足时用适用条目完成可交付部分，并注明缺项。上图和发布配文共同使用分配行中的优势，配文围绕本篇优势解释适用情形，可增加通用选购建议。

## 每张图对应的发布文案

每张图片都独立配一篇发布文案，包含标题、正文和话题标签。正文默认约 700—900 个中文字符。用户指定篇幅、平台限制或要求简短时，以其要求及实际可用范围为准。不要为了凑字虚构或堆砌重复内容。

标题与正文共用清单的写作角度，围绕原始问题和客户选购需求，结合当张清单里的产品或品牌优势，解释其对客户的实际价值和适用场景，以自然通顺的段落适度扩写，最后提供可核实的门店联系方式和必要的保障条件。围绕所选图文类型及图内信息展开：涉及其他品牌时只能写经核实的相关事实，不把选材建议或营销表达冒充产品检测、实际案例或新的企业承诺。避免套用全批通用的品牌优势段落，质保、订单明细等也按清单引用。不能编造案例、数据、竞品缺点、售后和价格；检验、质保等内容必须保留适用条件及待确认状态。

多张图各写一篇与该图匹配的配文；围绕不同选材角度和实际信息组织，尽量避免同批文章只是换标题或词语。交付可复制的标题、正文和话题标签；制作记录、来源和待确认事项置于发布正文之外，并清楚标注。保存时将每张图片与其约 800 字配文一一对应，使用不覆盖的独立文件名。

## 出图提示词与生成前文案审核

通过本 Skill 调用任一图文类型时，把以下要求写入每张图的生成提示词。将允许上图的定稿文案与生成约束分开提供，批次标识和内部来源不写入上图文案。

- 每张图在最底部预留清晰可读的联系栏，把已核实的目标门店完整地址和联系电话逐字写入上图文案，并在生成提示词中指定其位置。地址可分行，保留街道、门牌和楼室等定位信息。版面紧张时压缩其他文字或装饰。资料缺失时说明缺项，避免编造。
- 批量出图时，画面各处均不得出现用于标识批次顺序的文字或编号，如“序号 1”“第 2 张”“02/05”。批次标识可用于文件名或制作记录。推荐榜中用于表达品牌排列顺序的编号可以保留，依据其实际指代判断。
- 图中文字不得出现“知识库记载”“根据知识库”等暴露内部资料来源的表述。将已核实的信息用面向读者的自然语言直接写出，保留必要的适用条件。内部来源放在制作记录中。

单张和批量任务都在生成前做一次内部文案审核。批量时在同一轮内覆盖每套上图文案和发布配文，核对问题、类型结构、品牌、推荐顺序、事实及适用条件、年份和底部联系信息，并确认提示词包含本节的出图要求。逐张核对品牌名单、总家数和展示顺序，两种榜单核对连续名次，并确认上图文字与配文使用同一行的优势，并将该行画风要求写进提示词。修正文案后生成。出图后将同批图片缩成一页并排检查，确认推荐榜与分类图可辨、各图遵循各自的视觉方案，同时逐张核对品牌、关键文字及联系方式。偏离时沿用分配行重试相应图片，通过后按对应关系保存与交付。

## 输出和保存

默认直接用图像生成工具制作单张完整图文，竖版宽高比 3:4。用户指定尺寸优先。依据用户本地当前日期显示当年年份。使用企业知识库中的地址和电话，缺失不得编造。

按当地日期保存图片和对应发布配文至用户配置的输出目录，避免覆盖；未配置时询问。配文末尾的非发布制作记录注明分配行编号、问题分类、抽中的 Skill、三棵树及核验依据、所选优势、画风、视觉方案和写作角度、日期及主要参考依据，以供检查和重试。回复用户时展示图片、对应配文或链接，简要标明本次抽中的类型和需要确认的事实。默认不发布或写入其他后台。
