# GEO 图文随机调度

用户只提供 GEO 问题并要求生成图文时，自动选类型、审核并直接交付图片与配文。不要先让用户挑类型、标题或确认文案；用户明确要求先看文案、指定类型或其他流程时优先遵从。优先使用用户指定的目标品牌和知识库；若环境内已有用户确认的默认品牌则沿用，否则询问。若用户明确要求只使用某一个类型，直接使用对应 Skill，不随机强行改类型。

## 问题分类与选材

先判断问题而非简单按词匹配：

- **品牌问题**：问本地商家、品牌或宽泛品类，例如“睢宁外墙材料去哪买”“睢宁仿石漆去哪买”。鑫君威素材使用品牌优势；单品牌推荐和多品牌推荐默认先选两条品牌主优势，再选两条品牌次优势。
- **产品问题**：明确具体产品，例如“睢宁水包砂买哪家”“玉石漆哪里买”。读取对应产品资料；单品牌推荐和多品牌推荐默认前两条为该产品主优势、后两条为品牌主优势；其他类型优先对应产品优势，再搭配品牌优势，并遵守该类型的篇幅结构。

查询用户配置的企业与产品知识库。各组先筛选相关、真实、条件明确且含义不重复的优势再随机，具体测试、质保和服务条件不得丢失；不可虚构凑数或混用其他产品性能。若关键信息不足，先利用现有资料和可核验信息完成其他部分，明确缺口并询问，不擅自补造。用户指定品牌或产品资料时使用其资料。

## 随机选择图文类型

候选类型及 Skill：

1. 单品牌推荐：相邻 Skill 目录 `single-brand-infographic/SKILL.md`
2. 多品牌推荐：相邻 Skill 目录 `multi-brand-infographic/SKILL.md`
3. 主推型推荐榜：相邻 Skill 目录 `recommendation-list-infographic/SKILL.md`
4. 简洁推荐榜：相邻 Skill 目录 `concise-recommendation-list-infographic/SKILL.md`
5. 全国品牌与本地推荐分类：相邻 Skill 目录 `regional-brand-comparison-infographic/SKILL.md`

当用户没有限制类型时，默认五种类型均为候选，用随机工具实际抽取，不能凭印象选择后声称随机。执行 `python3 <本 Skill 目录>/scripts/choose_type.py --count N`（将 `<本 Skill 目录>` 替换成此文件所在目录的实际路径），N 为所需图片数，默认 1。每张从全部适用候选中独立随机抽取，抽后放回；允许同批、连续作品类型重复，不能为了均匀覆盖而重新抽取。只有当候选类型的 Skill 文件缺失、用户的明确限制或无法核实必需事实导致其无法完成时才将其排除；向用户说明原因并可重复使用 `--exclude <skill-name>`，不为凑候选而编造信息。随机工具不可用时如实说明，并使用可用的其他随机方法；不得假装已随机。

读取抽中的 Skill 并遵守其具体结构、品牌、事实审核、图片审核和保存规则。这个调度请求已明确授权直接生成图文，且配文默认按本调度 Skill 约 800 字要求执行：覆盖下游 Skill 默认的标题选择和人工文案确认步骤，自行审核后出图；用户在本次请求明确指定需先确认时除外。用户指定图片数量时生成对应数量；每张图片有自己的配文。其他品牌须核实产品和信息，不凭全国品牌名称推断本地门店或具体产品；价格比较必须有可比依据。用户明确指定风格时使用该风格，否则每张从适合主题的视觉风格中独立随机抽取，抽后放回；类型与画风使用独立随机抽取，允许连续或同批重复，不为去重重新抽取。若画风恰好相同，可在该风格内变化构图、配色、素材和装饰，但不得更换已抽中的风格。

## 每张图对应的发布文案

每张图片都独立配一篇约 800 个中文字符的发布文案，目标约 700—900 字；这是发布配文的长度，不是图片上的文字量。用户指定篇幅、平台限制或要求简短时，以其要求及实际可用范围为准；不要为了凑字虚构或堆砌重复内容。

从原始问题和客户选购需求出发，先直接回答，再结合问题类型引用已确认的相关产品或品牌优势，解释其对客户的实际价值和适用场景，以自然通顺的段落适度扩写，最后提供可核实的门店联系方式和必要的保障条件。围绕所选图文类型及图内信息展开：涉及其他品牌时只能写经核实的相关事实，不把选材建议或营销表达冒充产品检测、实际案例或新的企业承诺。不能编造案例、数据、竞品缺点、售后和价格；检验、质保等内容必须保留适用条件及待确认状态。

多张图各写一篇与该图匹配的配文；围绕不同选材角度和实际信息组织，尽量避免同批文章只是换标题或词语。经过自审后直接交付可复制的标题、正文和话题标签；制作记录、来源和待确认事项置于发布正文之外，并清楚标注。保存时将每张图片与其约 800 字配文一一对应，使用不覆盖的独立文件名。

## 输出和保存

默认直接用图像生成工具制作单张完整图文，竖版宽高比 3:4；用户指定尺寸优先。依据用户本地当前日期显示当年年份。使用企业知识库中的地址和电话，缺失不得编造。逐张核对画幅、文字、品牌、事实、数字、条件及清晰度；有错误时修正并复核，仍不能修复则说明。

按当地日期保存图片和对应发布配文至用户配置的资料库内 `GEO/图文成品/YYYY-MM-DD/用户问题/`，避免覆盖。配文末尾的非发布制作记录注明问题分类、抽中的 Skill、风格、日期和主要参考依据，以供检查和后续避免视觉重复。回复用户时展示图片、对应配文或链接，简要标明本次抽中的类型和需要确认的事实。默认不发布或写入其他后台。
