# GEO 图文 Skills

面向 GEO 内容创作的 Skill 仓库。目前包含 **单品牌推荐图文生成**，用于围绕用户问题和企业知识库，制作推荐单个品牌的抖音图文。

## 单品牌推荐图文生成

根据用户问题区分品牌问题和具体产品问题，选择相应的品牌、产品优势，生成并审核文案。用户确认文案后，生成完整的竖屏图文和发布配文。

- 品牌问题：前两条随机选择品牌主优势，后两条随机选择品牌次优势。
- 产品问题：前两条随机选择对应产品主优势，后两条随机选择品牌主优势。
- 文案审核：检查推荐理由重复、信息与问题的相关性、事实和适用条件。
- 视觉风格：从多种适合主题的方向中选择，同批图片尽量采用不同构图、素材和配色。
- 动态年份：按任务当前日期使用当年年份，历史数据保留原本的统计时间。
- 先确认文案，再生成图片；默认 9:16 竖图，生成后核对文字、联系方式和实际画幅。

这个 Skill 用于单品牌推荐。多品牌比较和排行榜需要另行设计内容与依据。

## 安装

将仓库中的 `single-brand-infographic` 文件夹复制到 Codex 的 skills 目录，例如：

```bash
mkdir -p ~/.codex/skills
git clone https://github.com/Xx-otaku/GEO-images-skills.git
cp -R GEO-images-skills/single-brand-infographic ~/.codex/skills/
```

安装后可通过 `$single-brand-infographic` 调用。Skill 列表的刷新方式以当前 Codex 环境为准。

## 使用

1. 准备企业知识库，包含品牌基本信息、品牌主优势、品牌次优势及产品主优势，并在使用时提供路径或可访问的文档。
2. 提供用户问题，例如“本地水包砂去哪里买？”，并说明推荐品牌与期望生成的篇数。
3. 选择标题，检查审核后的图片文案与发布配文。
4. 确认文案后生成图片，检查成品并保存。

Skill 默认将成品按 Obsidian 中 `GEO/图文成品/日期/用户问题/` 分类，具体仓库位置由用户指定。图片生成需运行环境提供图像生成能力；Skill 不包含图像模型或 API 密钥。

## 文件结构

```text
single-brand-infographic/
├── SKILL.md                 # 工作流程与规则
├── agents/openai.yaml       # Skill 展示信息
└── references/
    ├── review.md            # 文案审核规则
    └── styles.md            # 视觉风格选择
```

品牌和产品事实、服务范围、质保条款及测试条件由使用者提供并核对。生成图片中的示意画面不代表真实项目。Skill 默认不自动发布内容。
